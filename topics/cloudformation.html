CloudFormation Overview & Core Concepts

  • Declarative IaC: CloudFormation is a declarative way to outline your AWS infrastructure for almost all resources.
  • S3 Requirement: Templates must be uploaded to Amazon S3 before being referenced by CloudFormation during stack creation or updates.
  • Stack Management: Deleting a CloudFormation stack automatically deletes all artifacts and resources created by that stack.

Template Building Blocks

  • AWSTemplateFormatVersion: Identifies the capability version (default: "2010-09-09").
  • Description: Comments explaining the template purpose.
  • Resources: Mandatory section detailing AWS components to provision.
  • Parameters: Dynamic input parameters passed at stack execution.
  • Mappings: Hardcoded static variables ideal for mapping values by region, AZ, or environment.
  • Outputs: Exported values that can be referenced cross-stack.
  • Conditions: Logical rules determining whether resources are created.

Key Intrinsic Functions

  • !Ref: Refers to parameters or resource physical IDs.
  • !GetAtt: Fetches specific resource attributes (e.g., !GetAtt MyEC2.AvailabilityZone).
  • !FindInMap: Retreives a value from Mappings block: !FindInMap [ MapName, TopKey, SecondKey ].
  • !ImportValue: Imports exported output variables from another stack.
  • !Base64: Encodes plain strings (commonly used for EC2 UserData).

Deletion Policies & Features

  • DeletionPolicy: Delete (Default): Deletes the resource when the stack is destroyed (S3 buckets must be empty to succeed).
  • DeletionPolicy: Retain: Keeps the resource intact when the CloudFormation stack is removed.
  • DeletionPolicy: Snapshot: Takes a backup snapshot prior to deletion (RDS, EBS, ElastiCache, Neptune).
  • Stack Policies: JSON policies protecting explicit resources from accidental updates during stack modification.
  • Custom Resources: AWS Lambda-backed resources used for unsupported services or running custom scripts (e.g., emptying S3 buckets).
  • StackSets: Allows creating/updating stacks across multiple accounts and regions in a single operation.
