Amazon S3 Comprehensive Developer Notes

In-depth study material mapped directly to the AWS Certified Developer Associate exam objectives.

1. Fundamentals & Global Architecture

  • Buckets: Regional resources with a globally unique namespace across all AWS accounts.
  • Objects: Data files stored key-value style within buckets. Max size for a single object is 5 TB. Any object larger than 5 GB strictly requires Multi-part Upload.
  • Keys & Prefixes: Object paths act as string keys. Folders are logical prefixes (e.g., folder/file.txt), which dictate S3 performance partitioning.

2. Storage Classes & Lifecycle Management

  • S3 Standard: General-purpose storage; high availability (99.99%), low latency, no retrieval fees or minimum storage durations.
  • S3 Standard-IA / One Zone-IA: Designed for infrequent access. Requires a minimum object size of 128 KB and a minimum billing duration of 30 days.
  • S3 Intelligent-Tiering: Automatically shifts objects between access tiers without retrieval fees or operational overhead.
  • S3 Glacier Tiers:
    • Instant Retrieval: Millisecond access for archival data.
    • Flexible Retrieval: 3–5 hours (Standard), 1–5 minutes (Expedited), or 5–12 hours (Bulk). Minimum billing duration is 90 days.
    • Deep Archive: Lowest cost; retrieval takes 12–48 hours. Minimum billing duration is 180 days.

3. Encryption & Security

  • SSE-S3: Default server-side encryption managed by AWS using AES-256 keys.
  • SSE-KMS: Uses AWS KMS keys (x-amz-server-side-encryption: aws:kms). Provides audit trails via CloudTrail but is subject to KMS API rate limits.
  • SSE-C: Customer-managed keys passed via HTTPS headers (x-amz-server-side-encryption-customer-algorithm). S3 encrypts the data and discards the key immediately.
  • Access Control: Enforce transport security via Bucket Policies checking "aws:SecureTransport": "false". Account-level Block Public Access overrides permissive bucket rules.

4. Performance Optimization

  • Prefix Scaling: S3 supports up to 3,500 PUT/POST/DELETE and 5,500 GET/HEAD requests per second per prefix. Distribute keys across multiple prefixes to maximize throughput.
  • S3 Transfer Acceleration: Uses AWS Edge Locations over the global AWS backbone for fast long-distance uploads.
  • Byte-Range Fetches: Request specific byte segments (e.g., bytes=0-2097152) to parallelize downloads or fetch headers.

5. Advanced Operations & Integrations

  • S3 Versioning: Assigns version IDs to objects. Deletions without a Version ID place a Delete Marker; explicit version deletion requires MFA if MFA Delete is enabled (configurable only by the Root account).
  • Replication (CRR & SRR): Requires Versioning on both source and destination buckets. Does not replicate pre-existing objects or explicit version deletions.
  • Pre-Signed URLs: Temporary access grants for private objects using the creator's IAM privileges (max expiration: 7 days via CLI/SDK).
  • Event Notifications & Transformations: Triggers SQS, SNS, or Lambda on object events. S3 Object Lambda executes code to transform object payloads on GET requests.
